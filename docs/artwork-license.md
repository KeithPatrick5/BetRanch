# Artwork license note

The current Bet Ranch UI uses custom original SVG artwork generated inside this repository under `public/art/`. No Rainbet, Stake, provider-slot, or third-party casino artwork is included.

External asset sources reviewed for future use:

- Kenney assets: CC0/public domain game assets.
- OpenGameArt: mixed free licenses, requires checking each asset.
- SVG Repo / UXWing style sources: useful for open/commercial SVG references, but individual license checks are still required.

Current decision: use custom in-repo vector artwork for the casino tiles and hero so the front end has visual identity without attribution or license risk.
