# Bet Ranch Phase Plan

## Phase 0: Product rules and game math bible
Define the games, house edges, payout caps, bet limits, ledger rules, fairness model, supported currencies, admin controls, risk controls, and launch restrictions.

## Phase 1: Core casino shell
Build the compact dark UI, navigation, wallet surface, game lobby, live feed shell, bet history shell, rewards shell, account settings, and provably fair surface.

## Phase 2: Provably fair engine
Build shared server seed, server seed hash, client seed, nonce, rotation, reveal, and verification tooling.

## Phase 3: Ledger and internal test balance
Build append-only ledger, balance calculation, bet debit, payout credit, admin adjustments, reconciliation, and audit views.

## Phase 4: Dice
Build the first real game and connect it to fairness, ledger, bet history, and live feed.

## Phase 5: Limbo
Build multiplier-target gameplay, max payout protection, fairness verification, and instant repeat flow.

## Phase 6: Live activity system
Replace shell data with realtime global bets, high rollers, big wins, privacy mode, and game-specific feeds.

## Phase 7: Mines
Build 5x5 interactive grid, active session recovery, cashout, bust logic, multiplier progression, and verification.

## Phase 8: Rewards and ranks
Build wagered totals, rakeback accrual, daily claim, weekly bonus, rank progress, and admin reward controls.

## Phase 9: NOWPayments deposits
Build invoice creation, payment status polling, verified webhooks, pending deposits, confirmed deposits, underpay/overpay handling, and admin logs.

## Phase 10: Manual withdrawals
Build request flow, address validation, balance locking, admin approval, rejection, sent state, and ledger reconciliation.

## Phase 11: Plinko
Build risk modes, row counts, fair path generation, animation, multiplier buckets, and verification.

## Phase 12: Wheel
Build segment tables, risk presets, spin animation, result generation, payout, and verification.

## Phase 13: Keno
Build number selection, random pick, fair draw generation, multiplier table, payout, and verification.

## Phase 14: Hilo
Build fair deck generation, higher/lower choices, cashout, multiplier ladder, and verification.

## Phase 15: Tower
Build vertical risk ladder, bomb placement, row selection, cashout, bust, and verification.

## Phase 16: Crash
Build solo crash first. Global crash only after realtime infrastructure is stable.

## Phase 17: Blackjack
Build single-player blackjack with clear rules, fair deck, dealer logic, payouts, and verification.

## Phase 18: Small originals
Build Rock Paper Scissors, War, and one original crossing game with original branding.

## Phase 19: Admin control room
Build user search, ledger viewer, bet search, deposit review, withdrawal queue, RTP reports, risk flags, and audit logs.

## Phase 20: Risk and responsible gambling
Build restricted jurisdiction logic, session controls, deposit limits, loss limits, self-exclusion, duplicate account checks, and fraud flags.

## Phase 21: Compliance layer
Build terms acceptance, country rules, KYC trigger states, AML review queue, license display controls, and sanctions integration placeholder.

## Phase 22: Affiliates and creator codes
Build referral codes, creator codes, commission tracking, promo codes, races, and challenge campaigns.

## Phase 23: PWA/mobile polish
Build installable PWA, home icon, haptics, mobile betting ergonomics, performance tightening, and reduced motion.

## Phase 24: Realtime/performance hardening
Build websocket/realtime layer, idempotent APIs, anti-double-bet locks, queues, retries, and rate limits.

## Phase 25: Security audit
Audit auth, wallet, ledger, fairness, webhooks, withdrawal approval, race conditions, replay attacks, and client tampering.

## Phase 26: Invite-only real-money beta
Turn on tiny deposit limits, tiny bet limits, manual withdrawals, invite-only accounts, and daily admin review.

## Phase 27: Public launch
Launch with Dice, Limbo, Mines, Plinko, Wheel, Keno, Hilo, wallet, deposits, manual withdrawals, rewards, live feed, admin, and risk controls.

## Phase 28: Post-launch expansion
Add Crash, Blackjack, Tower, War, creator challenges, VIP tooling, trusted-user auto-withdrawals, and additional assets.
